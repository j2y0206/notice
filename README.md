# 우리 가족 나고야 여행 가이드

2026년 10월 28일~31일 나고야 가족여행을 위한 모바일 우선 정적 웹사이트입니다.

## 로컬 미리보기

PowerShell에서 이 폴더로 이동한 뒤 실행합니다.

```powershell
python -m http.server 4173
```

브라우저에서 `http://localhost:4173`을 엽니다.

## 구성

- 날짜별 시간순 일정
- 일정별 Google Maps 경로 버튼
- 계획한 노선·행선지·역번호 안내
- 아이들 컨디션에 따른 선택 일정 표시
- 서비스 워커 기반 오프라인 열람
- GitHub Pages에서 바로 호스팅 가능한 순수 HTML/CSS/JavaScript

Google Maps 경로와 외부 공식 사이트는 인터넷 연결이 필요합니다.
