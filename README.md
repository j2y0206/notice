# 우리 가족 나고야 여행 가이드

2026년 10월 28일~31일 나고야 가족여행을 위한 모바일 우선 정적 웹사이트입니다.

## 로컬 미리보기

PowerShell에서 이 폴더로 이동한 뒤 실행합니다.

```powershell
python -m http.server 4173
```

브라우저에서 `http://localhost:4173`을 엽니다.

## 구성

- 날짜별 시간순 일정
- 역할을 구분한 Google 지도·공식 시간표 버튼
- 단계별 탑승 순서와 노선·행선지·역번호 안내
- 아이들 컨디션에 따른 선택 일정 표시
- 공항·식당·교통·호텔·쇼핑·긴급 상황별 일본어 회화 35개
- 한글 발음, 한국어 뜻, 일본어 음성 재생과 문장 검색
- 현재 날짜와 시간에 맞춘 다음 일정 안내
- 기기에만 저장되는 가족 체크리스트와 현장 메모
- 경찰·구급·호텔·한국어 여행자 핫라인 긴급 카드
- 홈 화면 설치 안내와 오프라인 준비 상태 표시
- 서비스 워커 기반 오프라인 열람
- GitHub Pages에서 바로 호스팅 가능한 순수 HTML/CSS/JavaScript

Google Maps 경로와 외부 공식 사이트는 인터넷 연결이 필요합니다.
